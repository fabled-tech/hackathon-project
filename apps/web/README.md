# RightsRadar Web

This package contains the standalone Next.js demo for the hackathon.

## Deploy to Vercel

1. Import `apps/web` as the project root in Vercel.
2. Set `NEXT_PUBLIC_API_BASE_URL` if you want the demo to talk to a hosted API.
3. Deploy and share the generated public URL with judges.

If you leave `NEXT_PUBLIC_API_BASE_URL` empty, the demo UI still works as a polished static
walkthrough for the competition.

Fabled

One collaboration core, one industry layer per creative field. Each layer plugs into the tools that field already uses: Unreal Engine on the engine side, Higgsfield, Meshy and Tripo on the generation side.

🎬 Fabled Shots · film

Screenplay → scene breakdown → proposed shot list → storyboard and animatic → Higgsfield clips → Unreal Sequencer plan.

  1. Paste a script (sample included)
  2. Review the proposed coverage as director or DP
  3. Play the animatic, attach frames, animate with Higgsfield
  4. Export the shot list and the Unreal Sequencer builder

🕹️ Fabled Forge · games

Pitch → asset kit with studio import profiles → generate (Meshy / Tripo / offline mock) → validate in Fabled Studio → level blockout → Unreal.

  1. Paste a pitch (sample included)
  2. Work the task board with your team or vendor
  3. Generate meshes and track them to “validated”
  4. Lay out the level and export the Unreal blockout builder

Everything mocked, estimated or untested is labeled: CONCEPT MOCKUP for mock providers and placeholder frames, ESTIMATE for rule-based numbers. Unreal scripts are drafts and have not been run in the editor.

# Synthetic test fixtures

Generated by `python fixtures/make_fixtures.py`. All are programmatic box-figure proxies, not real art.

| File | What is deliberately wrong |
|---|---|
| `synthetic_clean_character.obj` | clean box-figure proxy, centimeters, 2 LODs, 2 materials |
| `synthetic_wrong_scale_meters.obj` | same proxy written in meters (1.8 units tall) |
| `synthetic_flipped_faces.obj` | 128 triangles (arm_r +X side, LOD0) with reversed winding |
| `synthetic_missing_texture.obj` | M_Body normal map references textures/T_Vendor_N.png (not on disk) |
| `synthetic_geometry_issues.obj` | one extra triangle on an existing torso edge (non-manifold) + 2 zero-area + 1 repeated-vertex triangle |
| `synthetic_uv_texture_issues.obj` | torso +Z UVs shifted to u>1; M_Body normal 'body_normal_final.png' 1000x1000; M_Body has no ORM; M_Head base color 8192x8 |
| `synthetic_clean_character.glb` | clean proxy in meters, skinned to 8-bone skeleton, textures embedded |
| `synthetic_wrong_root_bone.gltf` | skeleton root named 'hips' instead of 'root' (embedded base64 buffer) |
| `synthetic_bad_bone_names.gltf` | 3 bones break the naming regex: Pelvis, spine.001, mixamorig:LeftArm |
| `synthetic_storyboard_two_flags.gltf` | storyboard case: centimeter values written into a meters (glTF) file + 128 flipped triangles |
| `synthetic_storyboard_fixed.gltf` | storyboard case after fix: converted to meters, winding restored |
| `synthetic_clean_character.fbx` | clean proxy, binary FBX 7.4, UnitScaleFactor 1 (cm), skinned |
| `synthetic_wrong_unit_scale.fbx` | centimeter values but UnitScaleFactor 100 (file claims meters) |
| `synthetic_pipeline_out/` | synthetic pipeline output that matches its manifest (4 LODs, combined SM_SyntheticProxy.fbx) |
| `synthetic_pipeline_out_tri_mismatch/` | same, but manifest LOD1 triangles = 1252 (real: 1152) |
| `synthetic_pipeline_out_missing_lod/` | same, but SM_SyntheticProxy_LOD2.fbx deleted |

Textures in `textures/` are solid-colour PNGs. Their pixel dimensions are realistic (1024-2048 px) so texel density can be measured, but the files are a few KB each because a solid colour compresses to almost nothing.

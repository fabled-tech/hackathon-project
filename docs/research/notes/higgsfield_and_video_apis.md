## Key question 1: Does Higgsfield expose a public developer API in 2026? Base URL, auth, a concrete image-to-video endpoint, and the status-polling shape

### Takeaway
Yes. Higgsfield runs a public, pay-as-you-go developer API ("Open Higgsfield" / "Higgsfield API") at `https://api.higgsfield.ai`, with keys created in `console.higgsfield.ai` (also surfaced as cloud.higgsfield.ai / open.higgsfield.ai), authenticated with `Authorization: Key KEY_ID:KEY_SECRET`, an asynchronous submit-then-poll lifecycle (`request_id`, `status_url`, `cancel_url`), optional webhooks, and official Node/TypeScript and Python SDKs plus a CLI. The older `hf-api-key` / `hf-secret` header scheme is not what the current SDKs send; the current (V2) scheme is a single `Authorization: Key ...` header.

### Cited Findings
- Default API host in the official Node SDK is `https://api.higgsfield.ai` (`baseURL`); docs at `https://docs.higgsfield.ai`; status page at `https://status.higgsfield.ai`; package `@higgsfield/client`, MIT licence — [GitHub higgsfield-ai/higgsfield-js README](https://github.com/higgsfield-ai/higgsfield-js)
- Auth (SDK V2, "recommended"): one `credentials` value in `KEY_ID:KEY_SECRET` format, sent as header `Authorization: Key KEY_ID:KEY_SECRET`; env vars `HF_CREDENTIALS`, or `HF_API_KEY` + `HF_API_SECRET`. V1 (deprecated) used `apiKey`/`apiSecret` and env vars `HF_API_KEY` and `HF_SECRET`. V2 is server-side only; browser use is blocked ("BrowserNotSupportedError") — [GitHub higgsfield-ai/higgsfield-js README](https://github.com/higgsfield-ai/higgsfield-js)
- Higgsfield's own blog: "Authentication uses an `Authorization: Key` header with a key ID and secret, which you create in the console at console.higgsfield.ai. The secret is shown only once." Base URL `https://api.higgsfield.ai`; API reference is generated from an OpenAPI spec; official Python and TypeScript SDKs plus plain REST — [Higgsfield blog, "Meet the Higgsfield API"](https://higgsfield.ai/blog/higgsfield-api); [docs.higgsfield.ai "How the API works"](https://docs.higgsfield.ai/docs/how-to/introduction)
- Lifecycle as stated in the docs: "The Higgsfield API uses an asynchronous request lifecycle: Submit JSON parameters to a model endpoint. Store the returned request_id. Poll status_url or wait for a webhook. Download output when the request becomes completed." — [docs.higgsfield.ai "How the API works"](https://docs.higgsfield.ai/docs/how-to/introduction)
- Concrete image-to-video endpoint (per-model path style): `POST https://api.higgsfield.ai/wan/v2.7/image-to-video`, input image as a public URL in `image_url` — [docs.higgsfield.ai, Wan 2.7 image-to-video](https://docs.higgsfield.ai/docs/models/wan-2-7/image-to-video)
- Kling 3.0 Standard image-to-video on Higgsfield documents a first-frame image and an optional last-frame image, and "recommends always including a prompt" — [docs.higgsfield.ai, Kling 3.0 Standard image-to-video](https://docs.higgsfield.ai/docs/models/kling-3/standard-image-to-video). Turbo variant: [docs.higgsfield.ai, Kling 3.0 Turbo](https://docs.higgsfield.ai/docs/models/kling-3/turbo-image-to-video); Kling 2.6 Pro: [docs](https://docs.higgsfield.ai/docs/models/kling-2-6/pro-image-to-video); Kling 2.5 Turbo: [docs](https://docs.higgsfield.ai/docs/models/kling-2-5-turbo/standard-image-to-video)
- Seedance 2.5 "reference-to-video" takes an `image_urls` array instead of a single `image_url` (`{'image_urls': ['https://example.com/input.jpg']}`) — [docs.higgsfield.ai, Seedance 2.5 reference-to-video](https://docs.higgsfield.ai/docs/models/seedance-2-5/reference-to-video)
- Submission response: status `queued` plus `request_id`, `status_url` (form `https://api.higgsfield.ai/requests/REQUEST_ID/status`) and `cancel_url`; poll with GET using your API key until `completed`; finished video URL under `video.url`; terminal statuses `completed`, `failed`, `nsfw`, `canceled` — [docs.higgsfield.ai, Get request status](https://docs.higgsfield.ai/docs/api-reference/requests/get-request-status); [docs.higgsfield.ai Quickstart](https://docs.higgsfield.ai/docs/quickstart)
- SDK-level status enumeration (V2): `queued`, `in_progress` (cannot be cancelled), `nsfw` (rejected, credits refunded), `failed` (credits refunded), `completed` (media URLs returned). Response JSON: `status`, `request_id`, `status_url`, `cancel_url`, `images` (list of `{url}`), `video` (`{url}`). SDK polls `/requests/{request_id}/status`, default `pollInterval` 2000 ms, `maxPollTime` 300000 ms, client `timeout` 120000 ms, `maxRetries` 3 — [GitHub higgsfield-js README](https://github.com/higgsfield-ai/higgsfield-js)
- Webhooks: Node SDK takes `webhook: { url, secret }` and appends `?hf_webhook=<url>` to the endpoint URL; the README "does not describe the webhook payload or how to verify the secret". Python SDK exposes an optional `webhook_url` parameter "which calls your URL on completion" — [higgsfield-js README](https://github.com/higgsfield-ai/higgsfield-js); [higgsfield-client (Python) README](https://github.com/higgsfield-ai/higgsfield-client)
- Python SDK (`pip install higgsfield-client`): env `HF_KEY="your-api-key:your-api-secret"` or `HF_API_KEY`/`HF_API_SECRET`; functions `subscribe`/`submit`/`status`/`result`/`cancel`, `upload`/`upload_file`/`upload_image`; status values `Queued, InProgress, Completed, Failed, NSFW, Cancelled`; example model id `bytedance/seedream/v4/text-to-image` with `prompt`, `resolution`, `aspect_ratio`, `camera_fixed` — [GitHub higgsfield-ai/higgsfield-client](https://github.com/higgsfield-ai/higgsfield-client)
- Legacy V1 SDK endpoint examples still in the README: image-to-video `'/v1/image2video/dop'` with `model: 'dop-turbo'`, `prompt`, `input_images` (`{type:'image_url', image_url}`), motions via `inputMotion(motionId, 0.8)`; text-to-image `'/v1/text2image/soul'` (`width_and_height`, `quality`, `batch_size`, `style_id`, `style_strength`, `seed`, `custom_reference_id`, `custom_reference_strength`); speech-to-video `'/v1/speak/higgsfield'` (`input_image`, `input_audio` WAV only, `prompt`, `quality`, `duration`); `createSoulId({name, input_images})` — [higgsfield-js README](https://github.com/higgsfield-ai/higgsfield-js)
- FAQ: "if a request exceeds the timeout, it will be marked as failed and you will not be charged" — [docs.higgsfield.ai FAQ](https://docs.higgsfield.ai/docs/help/faq)
- Agent API (V2 preview, needs account access): `client.agents.sessions.create/run/send/messages/interrupt`, `client.agents.media.upload`; `run()` polls with 2–10 s backoff, default timeout 30 min; errors `AgentAccessDeniedError` (403), `SessionBusyError` (409), `NotEnoughCreditsError` (402) — [higgsfield-js README](https://github.com/higgsfield-ai/higgsfield-js)
- GitHub org (higgsfield-ai) repos as of Nov 2026: `skills` (agent skills, Python, updated Nov 5 2026), `higgsfield-video-engineer` ("Code-generated films rendered locally with a WebGPU path tracer; includes an agent skill", Nov 3 2026), `higgsfield-js` (Oct 29), `cli` ("Higgsfield CLI", Oct 22), `homebrew-tap`, `app-templates` (shadcn registry), `higgsfield-client` (Python, Sep 17), `cursor-plugin` (Aug 22) — [GitHub org repositories page](https://github.com/orgs/higgsfield-ai/repositories)
- The `skills` repo wraps the Higgsfield CLI (commands like `higgsfield website create`, flags `--soul-id`, `--video`, `--mode omni_reference --start-image`) and names model identifiers `gpt_image_2_6`, `nano_banana_flash`, `seedance_2_5`, `seed_audio`, `kling3_0_turbo`, `gpt_image_2`, `brain_activity` (Virality Predictor) — [GitHub higgsfield-ai/skills](https://github.com/higgsfield-ai/skills)
- Third-party wrappers (Segmind, Pixazo) host "Higgsfield-style" DoP models (`dop-turbo`, `dop-preview`) under their own keys; a reseller (VideoGenAPI) claims Higgsfield is text-to-video only, which contradicts the official docs — [Segmind](https://www.segmind.com/models/higgsfield-image2video/api); [Pixazo](https://www.pixazo.ai/models/higgsfield); [VideoGenAPI](https://videogenapi.com/higgsfield-api)

### Inferences
- The `hf-api-key`/`hf-secret` pair named in the brief appears to be the old V1 scheme (env var `HF_SECRET` still shows up in the V1 README); a 2026 integration should use `Authorization: Key KEY_ID:KEY_SECRET`.
- Model endpoints are now namespaced per model/version (`/wan/v2.7/image-to-video`, Kling 3.0 standard/turbo, Seedance 2.5 reference-to-video), while the Higgsfield-native legacy paths were `/v1/image2video/dop`, `/v1/text2image/soul`, `/v1/speak/higgsfield`. The blog's "switching models means changing one identifier in the request" suggests a uniform request envelope across these paths.
- The cloud/console/open hostnames all appear to be the same developer surface ("Open Higgsfield AI" title on both cloud.higgsfield.ai and console.higgsfield.ai).

### Gaps
- Webhook payload schema, signature-verification method, and retry policy: not documented in either SDK README; docs page not fetchable.
- Rate limits / concurrency caps: SDK README only says to use exponential backoff on rate limits with no figures. A third-party page title mentions a "7-Day Output Window" for API outputs ([novoads](https://novoads.ai/en/blog/higgsfield-api)) but this was not verified against official docs.
- Whether a Higgsfield-native text-to-video endpoint (as opposed to third-party models via Higgsfield) exists today: not confirmed.
- Exact request body for DoP under the V2 path scheme, and whether a `duration` field exists for DoP: not shown.

## Key question 2: Which models can be called through the Higgsfield API, with price per generation or per second?

### Takeaway
The API is a multi-vendor aggregator ("50+ video and image models") billed prepaid in USD with a $5 minimum top-up: video per second of output, images per image, Higgsfield's own DoP per generation, failed jobs free. Documented video models include Kling 2.5 Turbo/2.6/3.0/4.0, Wan 2.7/3.0, Seedance 2.0/2.5, "Genjutsu", plus Veo 3.1 and Higgsfield's own Soul/DoP/Speak; list prices run roughly $0.05/s (Wan 3.0) to $0.32/s (Genjutsu), with volume discounts to about half.

### Cited Findings
- Positioning: "access to 50+ video and image models with pay-as-you-go billing in US dollars: no subscription, published rates, failed requests free" — [Higgsfield blog "Meet the Higgsfield API"](https://higgsfield.ai/blog/higgsfield-api)
- Billing model: prepaid pay-as-you-go in USD, $5 minimum top-up; video per second of output, images per image; "DoP is the exception, priced per generation"; rates fixed per configuration regardless of top-up size; failed generations not charged — [open.higgsfield.ai/pricing](https://open.higgsfield.ai/pricing); [higgsfield.ai/higgsfield-api](https://higgsfield.ai/higgsfield-api)
- Sample list rates (from open.higgsfield.ai/pricing, read via search extract): Genjutsu from $0.318/s list ($0.159/s max discount); Seedance 2.5 from $0.206/s ($0.144/s); Seedance 2.0 from $0.141/s ($0.099/s); Wan 3.0 from $0.050/s ($0.025/s); Kling 3.0 from $0.084/s ($0.042/s); Kling 2.6 from $0.070/s ($0.035/s) — [open.higgsfield.ai/pricing](https://open.higgsfield.ai/pricing)
- Image models: Ideogram 4.0 $0.03/image; Soul 2 from about $0.003/image; Qwen Image 3 from $0.04/image — [open.higgsfield.ai/pricing](https://open.higgsfield.ai/pricing)
- Conflicting figures: Higgsfield homepage shows Kling 4.0 at $0.094/s; an older Higgsfield blog cites Kling 3.0 at $0.112/s at 1080p; a comparison blog lists Kling 3.0 at $0.042/s "API launch price" vs struck-through $0.084 — [higgsfield.ai](https://higgsfield.ai/higgsfield-api); [dev.to PopNow comparison](https://dev.to/popnow/what-ai-video-and-image-generation-really-costs-same-model-on-popnow-higgsfield-runway-and-fal-6do)
- Seedance 2.5 via Higgsfield: "about $0.2056 per generated second for 480p or $0.4622 for 720p, before any customer discount" for a 16:9 request without video input (third-party reading of Higgsfield's model overview) — [aireiter](https://aireiter.com/blog/higgsfield-ai-reviews-pricing-vs-api)
- Models with doc pages found: Wan 2.7 I2V, Kling 2.5 Turbo, Kling 2.6 Pro, Kling 3.0 Standard/Turbo, Seedance 2.5 reference-to-video — [docs.higgsfield.ai model pages](https://docs.higgsfield.ai/docs/models/wan-2-7/image-to-video)
- Models named in the official skills repo: Nano Banana 2, Soul V2, Veo 3.1, Kling 3.0, Seedance 2.5, Seed Audio 1.0, Flux 2, GPT Image 2.6 — [GitHub higgsfield-ai/skills](https://github.com/higgsfield-ai/skills)
- Legacy/native models in the SDK: DoP (`dop-turbo`), Soul text-to-image, Speak (speech-to-video), Soul IDs; text-to-image example `flux-pro/kontext/max/text-to-image` — [higgsfield-js README](https://github.com/higgsfield-ai/higgsfield-js)
- Consumer-side model guidance from Higgsfield's help center (which model to use) lists Soul (image, character consistency), DoP ("Higgsfield's native cinematography layer: VFX and directed camera moves applied through presets"), Popcorn (storyboard) — [Higgsfield help center, which model should I use](https://higgsfield.ai/creator-hub/help-center/ai-models/which-ai-model-should-i-use)
- Higgsfield's MCP connector offers "30+ image and video models" (third-party comparison) — [imageat.com fal vs Higgsfield](https://imageat.com/compare/fal-vs-higgsfield)

### Inferences
- For a previs product, the practical Higgsfield API menu is: Kling 3.0/4.0 (start+end frame), Wan 2.7/3.0 (cheapest), Seedance 2.5 (multi-reference, Cinema Studio's engine), Veo 3.1, plus DoP for preset camera moves. Prices on Higgsfield for Kling 3.0 ($0.084/s list, $0.042/s discounted) undercut Kling's own API list ($0.084/s at 720p per unit math below) only at the discounted tier.
- "Genjutsu" is a model name I could not map to a vendor; treat as unknown.

### Gaps
- No official per-generation DoP API price found (fal.ai does not appear to host DoP; search found no `fal-ai/higgsfield` endpoint).
- Full current catalog with resolution/duration matrices was not readable; whether Hailuo (MiniMax), Sora, or Runway models are exposed via Higgsfield's API is unconfirmed (only the consumer app is known to aggregate many models).
- Discount tier thresholds (what spend unlocks "max discount") were not found.

## Key question 3: What camera-control and cinematography features does Higgsfield have that matter for previs?

### Takeaway
Higgsfield's differentiator is directed camera control: Cinema Studio 4.0 (launched 28 Oct 2026, built on Seedance 2.5) offers 30+ camera-movement presets, five optically modeled lenses, four camera bodies, f/1.4–f/11 apertures, 50+ color grades, adjustable lighting, up to 50 reference images and clips up to 30 s; DoP applies preset camera moves/VFX; Soul ID holds a face across generations; Popcorn generates up to 8 consistent storyboard frames.

### Cited Findings
- Cinema Studio 4.0: camera presets rose "from 9 presets in 3.5 to 30+ in 4.0", new list includes POV, Robot Arm, Pan Left, Helicopter Shot; the five lenses were previously post-filters and "in 4.0 they are modeled optically during generation" — [Higgsfield blog, Cinema Studio 4.0](https://higgsfield.ai/blog/cinema-studio-4-0)
- Lens names: Clean Sharp, Anamorphic, Vintage Anamorphic, Warm Vintage, Halation Vintage; camera bodies Modern, 35mm Film, 8mm Film, DV Camcorder; apertures f/1.4 to f/11 — [Higgsfield blog, Cinema Studio 4.0 complete guide](https://higgsfield.ai/blog/cinema-studio-4-0-complete-guide)
- Color grading grew from 8 presets to 50+; lighting customizable for color, brightness, diffusion and angle; press release dated October 28, 2026 — [PR Newswire via Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/higgsfield-cinema-studio-4-0-130000643.html)
- 4.0 "runs on Seedance 2.5, supports up to 50 references, and produces clips up to 30 seconds" — [Higgsfield help center, How to use Cinema Studio](https://higgsfield.ai/creator-hub/help-center/tools/how-do-i-use-cinema-studio)
- Earlier reviews cite 30+ camera motion presets (dolly, crane, 360 orbit) and lens emulations (35mm film, vintage anamorphic, deep aperture) — [unite.ai review](https://www.unite.ai/higgsfield-ai-review/); [pixara review](https://www.pixara.ai/blogs/higgsfield-ai-review)
- Help article vs blog inconsistencies on preset counts for 3.5 noted by a reviewer — [Aliteq, Cinema Studio](https://aliteq.com/higgsfield-cinema-studio)

- Popcorn: announced October 23, 2025 as "an advanced AI storyboarding tool that creates visually consistent scenes from text prompts and reference images"; help article (Aug 2, 2026) calls it "a native AI storyboard generator that creates coherent sequences of up to 8 frames" — [Higgsfield blog, Popcorn](https://higgsfield.ai/blog/The-AI-Storyboard-Generator-That-Feels-Like-Directing); [help center, How to use Popcorn](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-popcorn)

API: `createSoulId`, `listSoulIds`, `custom_reference_id` in Soul text-to-image — [higgsfield-js README](https://github.com/higgsfield-ai/higgsfield-js)
- 3D: Higgsfield's 3D tool "outputs a GLB mesh that can be opened in Blender, Unity, Unreal, Godot, three.js" — [scriptable.com, How Higgsfield does 3D](https://scriptable.com/posts/higgsfield/3d-models/)
- Unreal Engine: Higgsfield's own X posts promote building games in Unreal Engine with Higgsfield-generated assets ("used Higgsfield to generated every asset"); these are promotional posts and no plugin/integration was independently confirmed — [Higgsfield on X](https://x.com/higgsfield_ai/status/2097403724356534333); [YouTube: Building a Game Environment in Unreal Engine with Higgsfield](https://www.youtube.com/watch?v=DUF8Wvg1ldw)

### Gaps

- Full named list of the 30+ camera presets (to map to previs vocabulary such as dolly-in, crane-up, FPV, bullet time): not retrieved; only POV, Robot Arm, Pan Left, Helicopter Shot, dolly, crane, 360 orbit are attested.
- Any official Unreal Engine plugin: none found; only promotional "Higgsfield + Unreal" content.

## Key question 4: Does Higgsfield offer anything for teams (shared workspaces, enterprise plans, brand kits)?

### Takeaway
Yes: Team (2–9 seats, pooled credits, standard queue), Scale (5–15 seats, priority queue, SSO, per-member spend controls) and Enterprise (15+ users, custom, no training on inputs/outputs, confidentiality, dedicated capacity, admin controls, user groups). Brand kits exist as an agent "skill" (higgsfield-brandkit) and inside Ads Studio. Seat pricing is inconsistently reported (~$65–79/seat/mo Team; $150–215/seat/mo Scale).

### Cited Findings
- Three business plans: Team is "a self-service shared workspace with pooled credits"; Enterprise is "custom, sales-arranged, with compliance, dedicated capacity, and advanced admin controls" — [Higgsfield help center, Team and Business plans](https://higgsfield.ai/creator-hub/help-center/business/team-and-business-higgsfield)
- Team: per-seat pricing, each seat's monthly credits pool into one workspace balance, standard queue, 2 to 9 seats. Scale: 5 to 15 seats, more credits per seat, priority queue, SSO, member spend controls (admins can pause an individual's credit usage). Enterprise: 15+ users, compliance needs or custom credit volume; "Inputs and outputs are excluded from model training and handled as confidential"; user groups with their own limits — [Higgsfield help center, Team and Business plans](https://higgsfield.ai/creator-hub/help-center/business/team-and-business-higgsfield); [How do Higgsfield plans work](https://higgsfield.ai/creator-hub/help-center/plans/how-do-higgsfield-plans-work)
- Seat prices (conflicting third-party reports): Team $79/seat/mo with 1,000 credits/seat pooled, or $65/seat annual vs $79 monthly; Scale $215/seat/mo with 2,500 credits/seat, or $150 annual / $169 monthly — [Krea blog on Higgsfield pricing](https://www.krea.ai/blog/higgsfield-pricing-explained-2026-unlimited-credits-and-real-monthly-costs); [camclo3d](https://camclo3d.com/blog/higgsfield-pricing); [Aliteq Team plan](https://aliteq.com/higgsfield-team-plan). Help center says current pricing is on the "Business plans" tab at higgsfield.ai/pricing.
- Individual plans reported at "$19 to $129/mo" (Krea) — [Krea blog](https://www.krea.ai/blog/higgsfield-pricing-explained-2026-unlimited-credits-and-real-monthly-costs)
- Brand kit tooling: `higgsfield-brandkit` skill ("palettes, SVG logo marks, typography, and brandbooks") — [GitHub higgsfield-ai/skills](https://github.com/higgsfield-ai/skills); Ads Studio "turns a website into finished static ads, with copy, visuals, and brand style included" — [Higgsfield blog, Ads Studio](https://higgsfield.ai/blog/higgsfield-ads-studio)
- "Contracted business revenue has grown 10× since June" (company statement, Sept 2026) — [Higgsfield blog, $1B run rate](https://higgsfield.ai/blog/higgsfield-1b-annualized-revenue-run-rate)

### Inferences
- For a previs product that uploads client script/concept art, only the Enterprise tier carries a contractual no-training commitment; Team/Scale inherit the default training licence (see Q6). The API's terms for training were not located and should be checked separately.

### Gaps
- Official seat prices, credit allocations and whether API usage can be billed to a Team/Enterprise workspace: not verified (pricing page unreachable).
- Enterprise SLA, data-residency, SSO protocol details: not found.

## Key question 5: Company facts (founders, funding, HQ, users, revenue, partnerships) and what people in film say

### Takeaway
Higgsfield is a San Francisco company founded by ex-Snap generative-AI lead Alex Mashrabov (CEO) with co-founder(s) Yerzat/Erzat Dulat (and, per some trackers, Mahi de Silva); it raised an $8M seed (Apr 2024, Menlo), $50M Series A (Sept 2025, GFT Ventures lead), $80M Series A extension (Jan 2026, >$1.3B valuation), $400M Series B (Aug 2026, DST Global lead, $5.4B valuation) and a Series B extension from Nvidia and TCV (Oct 2026, undisclosed); it claims a $1B annualized run rate (Sept 2026) and 32–40M users. ## Key question 6: Higgsfield terms — commercial use, ownership, data retention, training, prohibited uses

### Takeaway
Higgsfield's Terms of Use (last updated October 23, 2026) say it claims no ownership of inputs or outputs and does not restrict commercial use of outputs on any plan; but by default it licenses user inputs/prompts/outputs to train and improve its models, the only opt-out being deletion (prospective only) or an Enterprise agreement; private content is now expressly excluded from promotional use. An earlier version (Aug 30, 2025) with a "perpetual worldwide" licence caused a public backlash and was revised.

## Key question 7: Comparison set — Runway, Luma, Kling, Google Veo, MiniMax Hailuo, fal.ai, Replicate (API surface, pricing, webhooks, keyframes, durations)

Start+end-frame control exists on Runway (Gen-4 keyframes), Luma (start_frame/end_frame, plus up to 64 keyframes on Ray 3.2 via the Agents API), Kling 3.0 (first/last frame, incl. via Higgsfield), Veo 3.1 (first/last frame, 3 reference images, extension) and MiniMax Hailuo 02 (first/last frame). ## Key question 8: Legal comparison — indemnification, training on customer content, watermarking, likeness and copyrighted characters

### Takeaway
Google (Vertex AI paid tiers) is the only provider in the set with a documented output indemnity for generally available services, conditional on acceptable-use compliance and keeping SynthID; Runway offers IP indemnity only on Enterprise; Luma, Kling and Higgsfield standard terms offer none. Runway, Kling and Higgsfield train on customer content by default (Runway and Higgsfield exempt Enterprise; Runway's third-party model partners are contractually barred from training); Luma's API agreement reportedly prohibits training on API inputs/outputs, though sources conflict. Veo outputs carry an invisible SynthID watermark; Runway outputs carry C2PA metadata; free tiers on Kling, Runway, Hailuo and Luma carry visible watermarks. Likeness/copyrighted-character policies were not retrievable in this session.

### Cited Findings
- Google indemnity: "Google provides Enterprise Vertex AI customers with Generative AI Indemnification, covering third-party copyright infringement claims arising from training data or output content"; Veo listed among covered model families for eligible paid GA services; protection "contingent upon strict adherence to Google's Acceptable Use Policy", including not deliberately prompting infringing content and keeping default SynthID watermarks and safety metadata — [Atlas Cloud, Veo 3.1 pricing/ROI](https://www.atlascloud.ai/blog/tips/veo-3.1-api-pricing); [Synthedia on Google indemnity](https://synthedia.substack.com/p/google-adds-broad-generative-ai-indemnity); [Technology Magazine, Veo 3 on Vertex](https://technologymagazine.com/news/google-launches-veo-3-on-vertex-ai-for-enterprise-users)
- Veo commercial use tied to paid access; free-tier commercial terms unclear; "all videos contain SynthID watermarking" — [Global GPT guide](https://www.glbgpt.com/hub/can-i-use-veo-3-1-for-commercial-use/); [Everypixel Journal, 10 licences compared (Oct 2026)](https://journal.everypixel.com/ai-video-commercial-use)
- Runway: standard terms let Runway use inputs and outputs to train; Enterprise excluded; no general opt-out identified; "use of outputs is at the user's sole risk, with no indemnity for output, and the user must indemnify Runway"; Enterprise plan offers IP indemnification subject to Enterprise Services Terms; outputs include C2PA provenance metadata — [terms.law Runway](https://terms.law/ai-output-rights/runway/); [boring.insure AI indemnity guide](https://boring.insure/guides/ai-indemnity); [Everypixel Journal](https://journal.everypixel.com/ai-video-commercial-use)
- Runway third-party models: "Runway has secured contractual commitments from all third party model providers that they will not train on Customer Content, including inputs and outputs" — [Runway help, Enterprise FAQ third-party models](https://help.runwayml.com/hc/en-us/articles/51248305153683-Enterprise-FAQ-Third-party-Models-in-Runway); Runway Dev commercial-use page exists but was not fetched — [dev.runwayml.com/learn/commercial-use](https://dev.runwayml.com/learn/commercial-use)
- Luma: one source says "Luma's API agreement expressly prohibits training on customer API inputs and outputs"; another says Luma may use paid-plan inputs/outputs to train (API terms not reviewed by that source); public terms offer no indemnity and require users to defend Luma — [boring.insure](https://boring.insure/guides/ai-indemnity); [Everypixel Journal](https://journal.everypixel.com/ai-video-commercial-use)
- Kling: standard terms allow certain uses of customer content for AI training with an email-based revocation; no IP indemnification under standard consumer terms — [Everypixel Journal](https://journal.everypixel.com/ai-video-commercial-use)
- Visible watermarks: "Kling, Runway and Hailuo do add visible watermarks to no-cost output"; Luma free tier watermarked and cheapest paid plan keeps it — [whichoneisreal free limits](https://whichoneisreal.com/compare/best-free-ai-video/); [Everypixel Journal](https://journal.everypixel.com/ai-video-commercial-use)
- Higgsfield: no ownership claim, no commercial-use restriction, training by default except Enterprise, private content excluded from promotion (see Q6) — [Higgsfield Terms of Use](https://higgsfield.ai/terms-of-use-agreement); [MindStudio](https://www.mindstudio.ai/blog/higgsfield-terms-of-service-backlash)

### Inferences
- For a studio-facing previs product handling unreleased IP and actor likenesses, the provider ranking by contractual safety is: Google Vertex (indemnity + no-training under Cloud terms, as commonly reported) > Runway Enterprise > Higgsfield Enterprise > Luma API (if the no-training reading is correct) > Kling / Runway standard / Higgsfield standard.
- SynthID (Veo) and C2PA (Runway) are invisible/metadata provenance marks that do not block previs use but should be preserved to keep indemnity (Google).
